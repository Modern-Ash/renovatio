# Renovatio 0.3.0-alpha.1 Release Notes

Renovatio `0.3.0-alpha.1` is a technical preview, not a stable production
release.

## Support Classification

- Reference: offline COBOL-to-Java analysis, semantic IR, Java emission and
  modernization flow exercised by the release verification package.
- Beta: shared API, CLI, MCP and Workbench contracts where backed by completed
  AC-09 evidence.
- Experimental: Node emitter, JCL orchestration, architecture preview UI and
  governed LLM suggestion flows.
- Planned: production release support, remote hosted execution, additional
  target languages and unattended publication.

## Changes Since 0.2.0

- Repository governance baseline: Apache-2.0 license, contribution policy,
  security policy, code of conduct and repository hygiene rules.
- Architecture convergence docs: current and target architecture, capability
  classification and explicit experimental boundaries.
- Community alpha release package: release plan, SBOM, checksums, provenance,
  quickstart guidance and readiness report.
- Workbench alpha version alignment across the root package, browser
  application and core UI extension.

## Publication Gate

These notes describe the candidate package. Do not create the `v0.3.0-alpha.1`
tag, GitHub Release or distributable artifacts until the Spec Owner approves the
release-readiness report for the exact candidate SHA.
