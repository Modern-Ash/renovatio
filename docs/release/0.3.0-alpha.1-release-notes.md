# Renovatio 0.3.0-alpha.1 Draft Release Notes

Renovatio `0.3.0-alpha.1` is planned as a technical preview, not a stable
production release.

## Planned Support Classification

- Reference: offline COBOL-to-Java path after final gate evidence.
- Beta: common surface contracts where backed by completed AC-09 evidence.
- Experimental: Node, JCL, Python and remote LLM behavior unless final evidence
  promotes them.
- Planned: capabilities without build, characterization, equivalence and release
  evidence.

## Known Publication Blockers

- Repository license approval and `LICENSE` file from AC-03 / issue #224.
- Final release candidate SHA.
- Full clean-clone quick start evidence.
- SBOM, checksums, provenance and signatures.
- Spec Owner approval.
