# Renovatio 0.3.0-alpha.1 SBOM Summary

This source SBOM summary covers the `0.3.0-alpha.1` technical preview candidate.
The final GitHub Release must attach a machine-readable SBOM generated from the
approved tag commit before publication.

## Components

- Maven parent: `org.shark.renovatio:renovatio-parent:0.3.0-alpha.1`.
- Maven modules: `renovatio-semantic-ir`, `renovatio-domain-model`,
  `renovatio-jcl`, `renovatio-shared`, `renovatio-architecture`,
  `renovatio-application`, `renovatio-core`, `renovatio-provider-java`,
  `renovatio-provider-cobol`, `renovatio-mcp-server`, `renovatio-cli`,
  `renovatio-api`, `renovatio-cobol-runtime`, `renovatio-cobol-ir`,
  `renovatio-profile`, `renovatio-decisions`, `renovatio-llm`,
  `renovatio-evals`, `renovatio-persistence`, `renovatio-emitter-node`,
  `cobol-openrewrite-recipes`, `renovatio-cobol-annotations` and
  `renovatio-llm-runtime`.
- UI package: `renovatio-ui@0.3.0-alpha.1`.
- Workbench packages: `@renovatio/workbench@0.3.0-alpha.1`,
  `@renovatio/workbench-browser@0.3.0-alpha.1` and
  `@renovatio/core-ui@0.3.0-alpha.1`.

## Dependency Sources

- Maven dependencies are declared in module `pom.xml` files and resolved from
  Maven Central according to the checked-in POM graph.
- UI dependencies are locked in `renovatio-ui/package-lock.json`.
- Workbench dependencies are locked in `renovatio-workbench/package-lock.json`.

## Final Publication Requirement

Before publication, generate a machine-readable CycloneDX or SPDX SBOM from the
approved tag commit and attach it with checksums and provenance. This candidate
summary is intentionally conservative and does not replace the final attachment.
