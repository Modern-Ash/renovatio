# Community Documentation Checklist

The alpha documentation set must be internally consistent before publication.

## Required Public Docs

- `README.md`: quick start, supported toolchain, reference COBOL-to-Java path,
  limitations and links to deeper docs.
- `ARCHITECTURE.md`: as-is and target architecture aligned with the canonical
  pipeline.
- `CONTRIBUTING.md`: contribution flow and DCO sign-off.
- `SECURITY.md`: supported versions, reporting process and local-only safety
  model.
- `CHANGELOG.md`: changes since `0.2.0`.
- Capability matrix: support level and evidence per capability.
- Troubleshooting: common build, quick start and environment failures.
- Examples: runnable clean-clone sample for reference COBOL-to-Java flow.

## Consistency Rules

- No doc may claim production readiness.
- Experimental targets must be labelled experimental.
- Any remote LLM behavior must match the AC-08 completion state.
- Links and commands must be verified against the candidate SHA.
