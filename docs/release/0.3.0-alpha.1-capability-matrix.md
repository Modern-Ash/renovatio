# Renovatio 0.3.0-alpha.1 Capability Matrix

| Capability | Level | Evidence | Boundary |
|---|---|---|---|
| Offline COBOL-to-Java modernization path | Reference | Maven module graph, quickstart docs, release verifier | Technical preview only; not production support. |
| Semantic IR and COBOL runtime semantics | Reference | `renovatio-semantic-ir`, `renovatio-cobol-ir`, `renovatio-cobol-runtime` | Behavior must remain covered by characterization tests before refactors. |
| CLI, API and MCP surfaces | Beta | Completed AC-09 convergence evidence and module build coverage | Contracts may still change before 1.0. |
| Workbench shell and architecture preview | Beta | Workbench packages aligned to `0.3.0-alpha.1` | Requires Node `24.20.0` and npm `>=11`. |
| Node/TypeScript emitter | Experimental | `renovatio-emitter-node` module present | Not promoted as a stable migration target. |
| JCL parsing and Spring Batch projection | Experimental | `renovatio-jcl` module present | Unsupported utility steps become manual action items. |
| Governed LLM suggestion layer | Experimental | `renovatio-llm` and `renovatio-decisions` modules | Offline deterministic fallback remains mandatory. |
| Python target | Planned | `renovatio-provider-python` remains outside the Maven release graph | Lab package only; no supported COBOL-to-Python release path. |
| Hosted release artifacts | Planned | Release readiness report | No tag or GitHub Release before Spec Owner approval. |
