# Renovatio 0.3.0-alpha.1 Troubleshooting

## Maven Writes To `~/.m2`

Maven needs a writable local repository. In constrained sandboxes, rerun the
command with a writable Maven cache or outside the filesystem sandbox.

## Workbench Engine Mismatch

The Workbench requires Node `24.20.0` and npm `>=11`. Older Node versions may
install the lockfile only with `--engine-strict=false`, but that is not a valid
release build environment.

## Experimental Capability Expectations

Node, JCL and governed LLM flows are intentionally marked experimental in this
alpha. Failures in those paths should not be treated as regressions in the
reference COBOL-to-Java quickstart unless they affect shared core behavior.

## Workbench Audit Blocker

The Workbench currently depends on Theia `1.75.0`, which is the latest published
Theia package checked on 2026-09-11. npm audit still reports vulnerable Theia
transitives. Do not publish Workbench artifacts until patched upstream packages
or an approved mitigation are available.
