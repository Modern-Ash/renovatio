# Renovatio IDE shell command reference

| Command | Palette / Renovatio menu label | Default binding | Result |
| --- | --- | --- | --- |
| `renovatio.workbench.open` | Open Workbench Overview | — | Opens the Project area. |
| `renovatio.shell.project` | Open Project Area | `Ctrl/Cmd+Alt+1` | Opens project assets. |
| `renovatio.shell.analysis` | Open Analysis Area | `Ctrl/Cmd+Alt+2` | Opens analysis signals. |
| `renovatio.shell.architecture` | Open Architecture Area | `Ctrl/Cmd+Alt+3` | Opens architecture context. |
| `renovatio.shell.ai` | Open AI Area | `Ctrl/Cmd+Alt+4` | Opens governed AI context. |
| `renovatio.shell.equivalence` | Open Equivalence Area | `Ctrl/Cmd+Alt+5` | Opens equivalence evidence. |

All commands are contributed through Theia's command registry and appear in the command palette and
Renovatio menu. Keybindings can be overridden through normal Theia preferences.
