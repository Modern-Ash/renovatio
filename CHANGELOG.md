# Changelog

All notable changes to Renovatio will be documented in this file.

This project follows a pre-1.0 technical preview cadence. Entries are grouped by
release once the release is cut.

## 0.3.0-alpha.1

- Prepared the community technical preview release package with explicit
  reference, beta, experimental and planned capability levels.
- Aligned Maven, UI and Workbench package versions to `0.3.0-alpha.1`.
- Added release SBOM summary, checksums, provenance, troubleshooting and
  readiness report artifacts for Spec Owner review.
- Added `scripts/verify-alpha-release.sh` to verify candidate metadata,
  release artifacts and repository hygiene before publication.
- Added repository community health files and DCO contribution policy.
- Removed tracked local database/build artifacts from the source tree.
- Documented Agora evidence retention and repository hygiene policy for the
  architecture convergence release path.

- No unreleased changes.
